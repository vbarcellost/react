# Calculadora de IMC

Projeto React para calcular o Índice de Massa Corporal a partir da altura e do peso e exibir a classificação correspondente.

## Como executar

No Windows, dê dois cliques no arquivo `iniciar.bat`. O navegador será aberto automaticamente.

Ou execute pelo terminal:

```bash
npm install
npm run dev
```

> O arquivo `index.html` não deve ser aberto diretamente, pois o React precisa do servidor do Vite.

Para gerar a versão de produção:

```bash
npm run build
```

## Tecnologias

- React
- Vite
- CSS responsivo
